Questão 3:

a) Um container é ambiente isolado onde um processo pode ser executado, Uma imagem Docker é um pacote somente leitura, usado como base para criar containers.

b) Isso aconteceu porque o container foi criado utilizando uma imagem Docker antiga, que ainda contém a versão antiga do arquivo app.py, As alterações realizadas no código não são atualizadas automaticamente. 
Para resolver o problema o aluno pode construir a imagem novamente, parar o container antigo, remover o container antigo ou criar um novo container utilizando a imagem atualizada.
